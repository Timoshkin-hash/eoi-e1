# Экономика информатизации — решение экзаменационной задачи №1

Этот репозиторий содержит воспроизводимое решение задачи **«Оценка экономической эффективности внедрения облачной CRM»** для компании «ТехноПром». Анализ рассчитан на трёхлетний горизонт и включает прямой эффект, затраты, денежные потоки, NPV, простой срок окупаемости, ROI, визуализации и экономическую интерпретацию.

## Содержание

| Путь | Назначение |
|---|---|
| `notebooks/task_01_crm_efficiency.ipynb` | Основной исполняемый Jupyter Notebook с расчётами и выводами. |
| `data/task_01_crm_config.json` | Исходные параметры задачи в машиночитаемом формате. |
| `utils/calculations.py` | Вспомогательные функции расчёта NPV и простого срока окупаемости. |

| `reports/task_01_report.html` | Полный HTML-отчёт, экспортированный из выполненного notebook. |
| `reports/task_01_report.pdf` | Полный PDF-отчёт для просмотра и отправки преподавателю. |
| `docs/methodology.md` | Методологическое описание расчётной модели. |

## Ключевой результат

По исходным данным задачи ежегодный чистый поток в годах 1–3 составляет **5 356 800 руб.**, а NPV при ставке дисконтирования 12% — **11 066 129 руб.** Простой срок окупаемости при равномерном поступлении эффекта — **4,0 месяца**. Расчёт повторяет учебную трактовку, в которой прирост оборота признаётся эффектом до налогообложения; перед реальным инвестиционным решением его необходимо скорректировать на фактическую маржу и затраты на интеграцию.

## Установка и запуск

```bash
git clone https://github.com/Timoshkin-hash/eoi-e1.git
cd eoi-e1
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# Git Bash: source .venv/Scripts/activate
pip install -r requirements.txt
jupyter lab
```

Откройте `notebooks/task_01_crm_efficiency.ipynb` и выполните ячейки последовательно. Для безинтерактивного воспроизведения:

```bash
jupyter nbconvert --to notebook --execute --inplace \
  --ExecutePreprocessor.timeout=120 notebooks/task_01_crm_efficiency.ipynb
```

После выполнения notebook отчёт можно экспортировать командами:

```bash
jupyter nbconvert --to html --output-dir reports --output task_01_report notebooks/task_01_crm_efficiency.ipynb
```

PDF-версия отчёта также находится в `reports/task_01_report.pdf`.

## Методические замечания

В notebook используется прозрачное определение ROI: совокупный чистый эффект за годы 1–3 после первоначальных затрат делится на номинальные затраты проекта. Также отдельно пояснено, почему срок окупаемости 1,38 года не следует из показанных денежных потоков.
