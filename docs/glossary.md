# Глоссарий

| Термин | Определение |
|---|---|
| CRM | Информационная система для управления взаимоотношениями с клиентами, продажами и коммуникациями. |
| Денежный поток | Поступления и расходы проекта за определённый период. |
| NPV | Чистая приведённая стоимость проекта с учётом дисконтирования будущих денежных потоков. |
| ROI | Отношение результата проекта к затратам, выраженное в процентах. |
| Ставка дисконтирования | Норма, по которой будущие денежные потоки пересчитываются в текущую стоимость. |
| Простой срок окупаемости | Период возврата первоначальных затрат без учёта дисконтирования. |
| Парадокс производительности Солоу | Возможная ситуация, когда инвестиции в информационные технологии не дают немедленного наблюдаемого роста производительности. |
| Информационная асимметрия | Неравномерное распределение информации между участниками экономического процесса. |
